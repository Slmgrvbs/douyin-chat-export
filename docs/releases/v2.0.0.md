## 新增功能

本次正式发布汇总了 v1.0.1 之后的功能与修复。

- **语音转文字**：支持抖音原生语音识别、新消息增量识别与历史语音补全，识别结果可浏览、搜索和导出。
- **会话搜索与定位**：支持会话内文字、日期及媒体搜索，以及引用消息跳转到原始消息。
- **合并转发**：支持获取和展开查看合并转发聊天正文，并复用发送者昵称。
- **开放 API 与聊天长图**：新增 Bearer token 鉴权的只读接口，以及支持多主题的聊天长图渲染。
- **数据库迁移工具**：管理面板支持数据库导入、导出，改进全量抓取前的提示。
- **界面交互**：支持收起和重新展开会话列表，新增管理面板快捷入口，优化搜索侧栏与转发弹窗动画。

## 修复与改进

- 修复增量采集后的消息顺序，以及日期跳转后无法继续加载较新消息等双向分页问题。
- 改进分享卡片标题、作者、作品链接、封面比例及用户资料卡片展示。
- 改进旧消息内嵌图片、多种未分类媒体消息和系统通知的展示。
- 完善新消息格式的 ChatLab 导出，优化导出文件命名。
- 改进旧数据库兼容、媒体下载证书信任和消息加载错误提示。
- 优化搜索时阅读位置保持、消息气泡方向和日志隔离。
- 镜像发布成功后自动创建 GitHub Release，保留版本功能说明和升级记录。

## Docker 镜像与升级

支持 `linux/amd64` 和 `linux/arm64`：

```text
ghcr.io/teambreakerr/douyin-chat-export:2.0.0
```

本次发布同时更新 `2.0`、`2` 和 `latest` 标签。需要固定本次版本时，请使用 `2.0.0`。

升级前备份现有 `data` 目录，保留原来的数据卷挂载和环境配置。
将 Compose 中的镜像改为上述版本，然后执行：

```bash
docker compose pull
docker compose up -d
```

使用 `latest` 的部署也通过以上命令更新。本地源码构建的部署需更新源码并重新构建。
