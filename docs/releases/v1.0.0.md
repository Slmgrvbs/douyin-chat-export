## 首个正式版本

- **聊天采集**：通过抖音网页版 IM 接口获取私信及群聊历史，支持增量采集。
- **本地浏览**：提供 Web 聊天阅读界面、多主题、消息分组及图片放大查看。
- **媒体保存**：支持图片、语音和视频的本地下载，以及加密媒体处理。
- **聊天导出**：支持导出 ChatLab 格式的聊天记录。
- **管理面板**：提供登录、采集任务、定时执行和日志查看等管理功能。
- **Docker 部署**：发布 GHCR 预构建镜像，支持 amd64、arm64，简化安装；镜像仅安装 Playwright 无头浏览器组件。

## 稳定性改进

- 修复群聊发送者身份及群聊会话标识获取问题。
- 全量抓取失败或未取得消息时保留已有会话历史。
- 登录检测要求有效的非空 sessionid，避免误判登录成功。
- 改进 Windows 下的 UTF-8 输出和日志滚动体验。
